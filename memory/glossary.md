# Glossary

SPI とこのプロジェクトの用語。

## SPI 関連

| 用語 | 意味 |
|------|------|
| SPI | リクルート社の適性検査。言語・非言語・性格の3分野 |
| 語句の意味 | 言語分野の設問形式。ある語の意味として最も適切な選択肢を選ぶ |
| 二語の関係 | 言語分野の設問形式。例示された2語の関係と同じ関係のペアを選ぶ（例: 包含、用途、原料、同義、対義など） |
| 熟語の成り立ち | 二字熟語の構成（主述、修飾、対義の並列、動詞+目的語 など）を分類する設問 |

## 二語の関係・主なタイプ

| タイプ | 例 |
|--------|-----|
| 包含（A は B の一種） | 犬 : 動物 |
| 用途 | はさみ : 切る |
| 原料 | パン : 小麦 |
| 同義 | 進歩 : 発展 |
| 対義 | 需要 : 供給 |
| 一部 : 全体 | ページ : 本 |

## プロジェクト用語

| 用語 | 意味 |
|------|------|
| キュー(queue) | 1セッションで出題する語の並び。`lib/queue.ts` が生成 |
| セッション | 1回の学習（開始〜終了）。履歴に1レコード残る |
| 種データ | 本番語彙が揃うまでの仮の50語（`data/idioms.json`） |
| category=meaning | 「語句の意味」用の語 |
| category=relation | 「二語の関係」用のペア（将来対応） |
